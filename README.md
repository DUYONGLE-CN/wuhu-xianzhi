## 一、這是什麼

民國二年（1913）木活字重印本《蕪湖縣志》（清嘉慶十二年梁啓讓修、陳春華等纂）之**卷首與卷一《地里志》**的標點校勘稿。

校者：杜永樂　｜　賜教：me@duyongle.cn

**請先讀這五條，再讀正文：**

1. **只有一種底本。** 嘉慶十二年原刊本未獲見，故**無對校**。
2. 所校止於**本校**（本書前後互證）與**理校**（據文義、字形、制度推斷）；他校僅偶見，不成系統。
3. 因此本稿性質為**單底本標點校勘稿**，不稱「點校本」「精校本」「定本」，**不作定論引用**。
4. **校記**記已改者及其依據；**待核**記未敢定者，共 276 條。兩者分列，引用須並觀。
5. **本稿為人機協作產物，須明白交代**：初稿由大型語言模型逐葉讀圖轉錄（光學識別只用於定位與檢索，豎排繁體識別率不足半，不堪作底），再由校者逐葉對原圖核讀、斷句、出校記；模型所改必經校者覆核，未覆核者不入正文。凡涉史事考證，多經查檢原書或數據庫；一時未能核者，悉入待核。錯誤仍所難免，歡迎指正。

## 二、底本與來源

- **底本**：《蕪湖縣志》卷首、卷一（地里志），民國二年歲次癸丑陽曆秋十月邑人鮑寔重印木活字本。
- **來源**：國家圖書館「中華古籍資源庫」影印件（書號 312001066022，bid 73055）。
- 封面題「全八册」，是重印時全書規模；今所見影印件止此一册，故本稿所校僅為全書二十四卷之首一卷。
- 卷首含：書衣、重印序、宋鎔序、楊懋恬序、姚逢年序、梁啓讓序、吳嗣蕙識語、重修凡例、原修姓氏、重修職名、總目、原序七篇。
- 卷一含：卷端、地里志總序、沿革、疆域、星野、山川、風俗、方言、鄉都、市鎮。

## 四、體例要點

- 正文用繁體，**異體字照錄**，另編《異體字表》對照；形近訛字照錄並出校記，不逕改。
- 標點用新式標點，書名用《》，小注用（）；不依原葉列次分段。
- **校記集中於篇末，正文不加注碼**；每條校記末以（字詞）／（事實）標明性質。
- 闕字作 □，漫漶不可辨者出校記說明。
- 版心葉碼照錄原刻；重印本有改刻未盡處（如 p-51 版心仍題「風俗」而正文已入〈方言〉），一仍其舊。

## 八、校者自述

校者蕪湖人，生於是，長於是。先習計算機網絡技術，今秋始入漢語言文學專業，方讀第一學期。性喜鄉邦文獻，從事此稿，本為一己閱讀之便，非敢云著述；於音韻訓詁、職官沿革，尤茫無門徑。凡所改易，皆具校記；凡所疑而不能決者，悉入待核，不敢以意為斷。

自具兩短：一則學力未至，一則稿成於機器而責歸於人。轉錄之初，模型每有整列脫落、形近誤認、上下半錯位之失，校者逐葉回原圖覆核，凡改動皆見校記，凡未敢定者皆入待核；然模型疏漏未必盡為人所察，此尤可懼者。故本稿所存，止可視為進一步校勘之底，不可據為定論。

然疏漏必多：或誤改而失其真，或當改而仍其舊，或句讀一誤而文義全非。其最可能出錯者三處，先自陳於此——

- **方言一門**：音韻訓詁素未講求，注音切語尤易致誤；
- **所引史傳地志**：多憑檢索與記憶，未及一一覆核原書；
- **鄉都、市鎮諸表**：地名形近者眾，欄位易於串行。
